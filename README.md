# Portfolio

Portfólio pessoal de desenvolvedor full-stack. Site com tema escuro, animações suaves e layout editorial focado em apresentar projetos e habilidades técnicas.

## Funcionalidades

- Animações de entrada e scroll com GSAP + ScrollTrigger
- Menu mobile com transições suaves
- Header fixo com backdrop-blur ao rolar
- Layout 100% responsivo
- Marquee infinita com stack tecnológica
- Deploy automático via GitHub Actions + Vercel

## Tecnologias

| Camada | Tecnologia |
|---|---|
| Framework | React 19 + Vite 8 |
| Animações | biblioteca GSAP + ScrollTrigger |
| Estilização | CSS (Custom Properties) |
| Deploy | Vercel |
| CI/CD | GitHub Actions |

## Como rodar

```bash
npm install
npm run dev
```

## Deploy

O deploy é feito automaticamente via GitHub Actions ao fazer push para a branch `main`. O site é hospedado na Vercel.

🔗 **[Acesse o site aqui](https://portifolio-pi-seven-11.vercel.app/)**
